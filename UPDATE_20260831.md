# Crushing App — Update 31-08-2026

Perbaikan yang sudah dimasukkan pada paket ini:

1. **Member Import** menggunakan shared top navigation dan CSS aplikasi sehingga tampilannya konsisten dengan halaman lain.
2. **Member Import / Account Management**: Admin dapat mengubah role member atau menghapus member. Import Excel juga sekarang dapat memperbarui data member existing jika NPK, nama, atau role berbeda; password existing tidak di-reset.
3. **Production**: setelah ticket berhasil dibuat, halaman detail menampilkan popup singkat **Transaksi Berhasil** dengan check hijau dan animasi.
4. **MARIS**: tersedia **Edit Ticket** pada ticket Approved / MARIS Completed. Perubahan Qty atau penghapusan part hanya dapat disimpan setelah memasukkan password salah satu account **Admin Aplikasi** yang aktif.
5. **Audit**: perubahan Qty / penghapusan part dicatat pada Activity Log.
6. **Pulling**: kartu KPI dibuat lebih profesional dengan background putih, icon, accent bar, dan hierarchy yang lebih ringan daripada blok warna penuh.
7. **Production multi-part** tetap dipertahankan, termasuk Pilih Semua dan Qty per part.
8. **Export** NIK dan Operator Name tetap dipertahankan.

## Menjalankan project

Buka terminal di folder project, lalu:

```powershell
python -m venv venv
.\venv\Scripts\python.exe -m pip install -r requirements.txt
.\venv\Scripts\python.exe app.py
```

Jika folder `venv` sudah ada dan berfungsi, tidak perlu membuat ulang.

## Catatan penting

- Jangan menghapus `instance/database.db` jika ingin mempertahankan database saat ini.
- Password untuk fitur Edit Ticket adalah password account dengan role **ADMIN**, bukan password MARIS.
- Untuk menghapus member, gunakan **Kelola Member** pada halaman Member Import (khusus Admin).
